# What to Cook Next? 🍳

Take the cognitive load out of meal planning! This smart web application tracks what you've cooked recently to intelligently generate fresh daily menus, prevent recipe repetition, and export full weekly planners. 

**Stop thinking. Start cooking.**

## 🌟 Features

- **Intelligent Meal Generator:** Automatically generates Daily and Weekly meal plans based on your cooking history.
- **Recipe Roulette ("Surprise Me"):** Can't decide? Let the app randomly suggest 3 to 7 recipes based on your preferred meal type and season.
- **Smart Rotation Algorithm:** Remembers what you cooked recently. Won't suggest the same main dish within 3 days to prevent food fatigue.
- **Weekly PDF Exports:** Download your weekly meal plan as a clean, formatted PDF to stick on your fridge.
- **Beautiful Dark Mode:** Fully responsive, premium UI that automatically adapts to your system's light or dark mode preferences.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/abhinavRai23/what-to-cook.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd what-to-cook
   ```
3. **Install NPM packages**
   ```bash
   npm install
   ```
4. **Start the development server**
   ```bash
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173`

## 👨‍💻 Usage

- Head to the **Recipes** tab to browse your full catalog of meals and filter them by season or category.
- Head to the **Planner** tab to generate your menu for today, plan your whole week in advance, or get random suggestions.
